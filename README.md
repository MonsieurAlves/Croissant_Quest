# Croissant Quest — Pac-Alves

A playful browser maze game prototype.

## Version 0.1
- Navigate a maze using arrow keys, WASD, or on-screen arrows
- Collect croissants for points
- Win after collecting all reachable croissants
- Reset, pause, and resume
- Monsieur Alves cartoon avatar borrowed from the companion Conjugaison Quest game

## Files
- `index.html`: page structure
- `style.css`: visual style
- `game.js`: gameplay logic

## Publishing
Open **Settings → Pages** and set the source to **Deploy from a branch**, branch **main**, folder **/(root)**. After deployment the game will be available at:
https://monsieuralves.github.io/Croissant_Quest/

This is a learning prototype; future updates can add coworker ghosts, animated mouths, levels, and sound effects.
